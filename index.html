Guía Paso a Paso: Publicar esta Web GRATIS

Aprende a alojar este portal con HTTPS, SSL y Dominio SSL/Subdominio sin pagar un centavo.

100% Gratuito y Perpetuo

GitHub Pages

usuario.github.io
  1. Crea una cuenta gratis en GitHub.com.
  2. Crea un repositorio llamado mi-portal-ti.
  3. Sube este archivo renombrado como index.html.
  4. Ve a Settings > Pages y en Branch elige Main. ¡Listo!

Vercel CLI / Web

mi-proyecto.vercel.app
  1. Regístrate en Vercel.com con tu cuenta de GitHub.
  2. Haz clic en "Add New Project" e importa tu repositorio.
  3. Vercel detectará el archivo HTML automáticamente.
  4. Obtienes CDN global ultra rápida y SSL en segundos.

Netlify & Dominios

Drag & Drop / DNS

Entra a Netlify Drop y arrastra la carpeta con el index.html.

¿Dominios Gratuito Personalizado?

Usa servicios como DuckDNS o regístrate en registradore libres para Vincular CNAME / A Records en la configuración DNS de tu hosting gratis.
